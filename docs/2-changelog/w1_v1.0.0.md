## Changes

Initial implementation of `spokes`, a CLI dependency-shape linter for TS/JS repositories. Parses
the static import graph, classifies every file as a **hub** (in-degree ≤ 1) or **spoke**
(out-degree ≤ 1), enforces those degree rules plus acyclicity (rules R1–R4), and mechanically
renders the graph as a Mermaid/DOT/self-contained-HTML architecture diagram. Covers milestones
M0 (skeleton: parse/resolve/build graph, `explain`), M1 (checker: R1–R4, exit codes, `--json`),
and M2 (visuals + `suggest`) — the shippable v1 per the PRD. M3 (write-mode, watch mode,
incremental cycle checking, non-TS adapters, LSP) is explicitly out of scope.

- Five CLI commands: `init`, `check [--json]`, `graph [--format mermaid|dot] [--no-timestamp] [--out <dir>]`, `suggest`, `explain <path>`.
- Deterministic, dependency-free-of-AI diagnostics for spoke fan-out (S001), hub multi-ownership (S002), circular dependencies (S003, iterative three-color DFS), and multi-export files (S004).
- `suggest` proposes deterministic cycle-extraction previews (shared hub file stub + rewiring diff), never auto-applied.
- All 10 PRD §11 acceptance fixtures (`fixtures/f01`–`f10`) pass against committed `expected.json` snapshots; the tool's own `src/` is organized as hubs/spokes and passes `spokes check` itself (dogfooding, `tests/meta.test.ts`).
- 32 vitest tests: R1–R4 unit tests with diagnostic messages inline-snapshotted verbatim against the PRD's literal examples, a fixtures suite, a graph-output determinism test, an E-RESOLVE regression test (caught and fixed during code review), and the meta-dogfooding test.
- Runtime deps limited to `typescript`, `fast-glob`, `commander` per the build spec; JSON-schema validation and role-glob matching are hand-rolled to stay within that constraint.
