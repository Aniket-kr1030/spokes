## Changes

Addressed a structural readability complaint: a flat Mermaid flowchart of every file and every
import edge reads as an undifferentiated "hairball" as the file count grows, with no way to
isolate a single file's context.

- **Directory clustering**: nodes are now grouped into one Mermaid `subgraph` per containing
  directory (`src`, `src/core`, `src/rules`, `src/render`, ...), so related files visually cluster
  together instead of scattering across the whole diagram.
- **Click-to-focus**: clicking any file in `spokes-graph.html` dims everything except that file
  and its direct connections; a "Clear focus" button resets. Verified this correctly reflects the
  tool's own edge semantics — e.g. clicking `src/cli.ts` correctly shows `src/types.ts` as *not*
  connected, since that's a `type`-only import that creates no edge under `typeOnlyEdges: "ignore"`.
- **Line routing**: switched Mermaid's edge curve from the default smooth/overlapping style to
  right-angle `step` routing, so individual connections read as distinct traceable segments
  instead of tangled diagonal splines.

Scoped to `src/render/mermaid.ts` (directory grouping; the required `.mmd` node id/label/style
rules from the PRD are otherwise unchanged) and `src/render/html.ts` (interaction + curve style).
No new dependencies — click-focus resolves Mermaid's deterministic SVG element ids and parses this
file's own diagram-source text, rather than any external library. Verified across several rounds
of live browser testing (screenshots, clicks, scroll-zoom) directly with the requester. All 32
existing tests still pass unchanged, including the `.mmd`/`.html` determinism test.
