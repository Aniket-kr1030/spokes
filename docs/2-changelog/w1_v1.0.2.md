## Changes

Fixed scroll-to-zoom feeling too sensitive in `spokes-graph.html`'s pan/zoom viewer (introduced
in v1.0.1): each wheel event previously applied a fixed ±10% zoom step, which felt jumpy
especially on trackpads that emit many small wheel events per gesture. Zoom is now proportional
to scroll magnitude (`Math.exp(-deltaY * 0.0015)`) for smooth, controlled zooming regardless of
input device. Also fixed zoom always anchoring at the content's top-left corner, which made the
view jump around on every zoom — it now anchors under the cursor position, so the point you're
looking at stays fixed on screen while zooming.

Scoped entirely to `src/render/html.ts`. Verified interactively via live scroll tests in a browser
session. All 32 existing tests still pass unchanged.
