## Changes

Fixed two usability bugs in the `spokes graph` command's generated `spokes-graph.html`, both
reported directly after visual inspection:

- **Dark-mode visibility**: the page had no explicit background color, so on a browser with
  dark mode enabled it rendered dark text on a dark page — the header, legend, and diagram were
  effectively invisible. Fixed with an explicit light background and `color-scheme: light`,
  independent of the viewer's OS/browser theme.
- **Diagram too small to read or navigate**: Mermaid's default behavior shrinks the flowchart to
  fit the page width, which made a 22+ node graph illegibly tiny with no way to inspect it.
  Replaced the static auto-render with a pan/zoom-capable viewport: scroll-wheel zoom, drag-to-pan,
  explicit zoom in/out buttons, and a "fit to screen" control that computes an initial scale from
  the rendered diagram's actual size. No new JS dependency — hand-written, consistent with the
  build spec's "no other JS dependencies" constraint.

Scoped entirely to `src/render/html.ts`; the required `spokes-graph.mmd` output and its
`flowchart TD` content are unaffected. Verified interactively in a live browser session (zoom,
pan, and reset all confirmed working). All 32 existing tests still pass unchanged.
